## 1. 环境要求

| 项 | 版本 |
|---|---|
| 操作系统 | Linux（Ubuntu 22.04+） |
| Python | 3.11+ |
| Node.js | 20+ |
| 数据库 | PostgreSQL 15+（开发可用 SQLite） |

## 2. 本地启动

```bash
# 后端
cd src/backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env             # 填写密钥，.env 不提交
uvicorn app.main:app --reload

# 前端
cd src/frontend
npm install
npm run dev
```
