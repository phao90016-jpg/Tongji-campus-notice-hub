## 1. 环境要求

| 项 | 版本 |
|---|---|
| 操作系统 | Linux（Ubuntu 22.04+） |
| Python | 3.11+ |
| Node.js | 20+ |
| 数据库 | PostgreSQL 15+（开发可用 SQLite） |

## 2. 本地启动

```bash
# 后端
cd src/backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env             # 填写密钥，.env 不提交
uvicorn app.main:app --reload

# 前端
cd src/frontend
npm install
npm run dev
```

## 6. 演示脚本

> 期末答辩用。功能演示 + 非功能演示各一项。

### 演示 1（功能）：多源聚合

1. 登录（GitHub OAuth）
2. 添加 2 个订阅源
3. 触发抓取，展示汇总通知流
4. 打开一条通知，跳转原文

### 演示 2（非功能）：幂等去重

1. 记录当前通知总数
2. 重复触发同一源抓取 3 次
3. 再次查看总数，数量不变

### 演示 3（非功能）：越权拦截

1. 账号 A 记录自己的待办 ID
2. 账号 B 请求该 ID
3. 返回 403 且不泄露内容
