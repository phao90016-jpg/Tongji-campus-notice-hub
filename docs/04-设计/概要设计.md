## 2. 体系结构风格与选型理由

**选择：前后端分离的分层架构 + 适配器模式**

| 层次 | 职责 | 关键模块 |
|---|---|---|
| 表现层 | Vue 3 SPA | `src/frontend` |
| 接口层 | REST API，鉴权与参数校验 | `app/api` |
| 应用层 | 用例编排 | `app/services` |
| 领域层 | 实体与规则 | `app/models` |
| 接入层 | 各信息源适配器 | `app/adapters` |
| 基础设施 | 数据库、调度、通知 | `app/core` |

**为什么用适配器模式**：对应风险 R1，把"源结构变化"的影响隔离在单个适配器内，
新增来源只加适配器不改上层（可演进性）。详见
[`src/backend/app/adapters/README.md`](../../src/backend/app/adapters/README.md)。
