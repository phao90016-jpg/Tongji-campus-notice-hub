## 2. 表设计

### user 用户

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | bigint | PK | |
| github_id | varchar(64) | unique, not null | GitHub 用户 ID |
| username | varchar(64) | not null | |
| email | varchar(128) | | 可为空 |
| role | varchar(16) | not null | student / publisher / admin |
| class_id | bigint | FK, null | 班委所属班级 |
| created_at | timestamp | not null | |

### notice 通知记录

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | bigint | PK | |
| source_id | bigint | FK, not null | |
| title | varchar(256) | not null | |
| content | text | | |
| url | varchar(512) | | 原文链接 |
| published_at | timestamp | | |
| fingerprint | char(64) | not null | 内容指纹，去重依据 |
| course_id | bigint | FK, null | |
| category_id | bigint | FK, null | |
| status | varchar(16) | not null | 新接收 / 已归类 / 已生成待办 / 已归档 |
| created_at | timestamp | not null | |

**索引**：`unique(source_id, fingerprint)`、`index(status, published_at)`

### todo_item 待办事项

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | bigint | PK | |
| user_id | bigint | FK, not null | 归属校验依据 |
| notice_id | bigint | FK, null | 来源通知 |
| title | varchar(256) | not null | |
| due_at | timestamp | null | 截止时间 |
| status | varchar(16) | not null | 草稿 / 已确认 / 进行中 / 已完成 / 已过期 / 已取消 |
| created_at | timestamp | not null | |

**索引**：`index(user_id, status, due_at)`

### reminder_task 提醒任务

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | bigint | PK | |
| todo_id | bigint | FK, not null | |
| plan_time | timestamp | not null | 计划发送时间 |
| status | varchar(16) | not null | pending / sending / sent / failed / dead |
| retry_count | int | not null default 0 | |
| sent_at | timestamp | null | |

**索引**：`index(status, plan_time)`

> 其余表（source、source_type、fetch_task、course、category、todo_status_log、
> reminder_rule、collection、tag、import_record、publish_record、audit_log、system_config）
> 按同一格式补充。

## 3. 约束与完整性

| 约束 | 说明 |
|---|---|
| 外键 | 全部显式声明，删除策略明确 |
| 唯一键 | `(source_id, fingerprint)` 保证去重 |
| 状态机约束 | 状态迁移只能经 service 层，禁止直接 UPDATE 状态字段 |

## 4. 迁移策略

- 使用版本化迁移脚本，禁止手工改线上表结构
- 迁移脚本与代码同一 PR 提交
